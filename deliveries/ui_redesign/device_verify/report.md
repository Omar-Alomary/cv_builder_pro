# تقرير فحص CV Builder Pro على Samsung SM-N975U

## طريقة التحقق

تمت مراجعة معاينات القوالب العشرة بصرياً على الهاتف، مع حفظ لقطات من الشاشة الفعلية. لتوحيد البيانات وتجنب تكرار إدخالها، مُلئت بيانات أحمد محمد العُمري برمجياً داخل شاشة الإنشاء الفعلية؛ لم تُكتب جميع الحقول يدوياً عبر لوحة المفاتيح. التنقل والمعاينة والاستيراد ومحدد الملفات وتغيير القالب جرت على التطبيق المثبت على الهاتف.

نسختا العربية والإنجليزية هما خمسة تصاميم في لغتين، وليستا عشرة تصاميم مختلفة. احتُفظ بالاسم والملخص العربي والمسمى الإنجليزي في بيانات التجربة حتى في القوالب الإنجليزية لاختبار المحتوى المختلط. ترتيب الأقسام يتبع تصميم كل قالب؛ Technical يعطي المهارات والمشاريع أولوية. ATS يستخدم عناوين الأقسام القياسية الإنجليزية في النسختين.

ملفات PDF المرفقة أُنشئت من نفس البيانات والخدمة المستخدمة في المعاينة، وقورنت بصرياً بعد إصلاحات الخطوط وتقسيم الصفحات. كل سيرة تجريبية تقع في صفحتين. صور *_page_2.png لقطات أثناء التمرير وليست صوراً كاملة مستقلة للصفحة الثانية.

## تغيير القالب

أُضيف زر لوحة الألوان إلى شريط شاشة الإنشاء وإلى بطاقة النشاط الأخير. المحدد يعرض القوالب العشرة بصورها الحالية وعلامة اختيار القالب النشط. يحفظ الاختيار عبر آلية الحفظ الحالية، مع رسالة نجاح؛ الإلغاء واختيار القالب الحالي لا يغيران البيانات، وفشل الحفظ لا يستبدل السيرة الأصلية.

على الهاتف: تغيّر قالب السيرة المحفوظة Technical إلى Classic من بطاقة Home، ثم Classic إلى Modern من شاشة الإنشاء، وظهرت معاينة Modern. بقيت هوية السيرة وجميع الحقول كما هي عدا templateId ووقت التحديث.

[محدد القالب](change_template_dialog.png) — [معاينة Modern بعد التغيير](change_template_after.png) — [زر Home](change_template_home_button.png) — [محدد Home](change_template_home_dialog.png).

## الإصلاحات

- إصلاح قارئ PDF لقواميس النص، وتجميع الحروف، وActualText وReversedChars، ومعالجة لام-ألف دون قلب الحروف داخلها.
- فصل أقسام السيرة العربية والإنجليزية إلى حقولها، وتصحيح الهاتف والعنوان والتواريخ، ومنع خلط البريد بالعناوين أو نسخ كامل الملف إلى الملخص.
- جمع المهارات التي تلتف إلى سطر آخر قبل تقسيمها؛ بقيت user interface (UI) implementation وproblem solving عبارتين كاملتين، وأصبح الملفان 27 مهارة.
- إصلاح الحرف العربي «ي» بصيغته المعزولة عند غياب خرائطه في خط Cairo، مع الاحتفاظ بالتشكيل دون تغيير ملفات الخطوط.
- إضافة فواصل ATS وBusiness، وتمييز عنوان Technical، وإبقاء عنوان القسم مع محتواه عند تقسيم الصفحات.
- إعادة استخدام صور assets/templates الموجودة دون إعادة إنشائها، ودون إضافة اعتماديات أو تغيير منطق المستودع والحفظ.

## القيود

PDF المصور يحتاج OCR غير متاح حالياً. استخراج السير ذات التنسيقات غير القياسية يظل تقريبياً ويحتاج مراجعة المعاينة قبل الحفظ؛ النجاح هنا يخص الملفين الفعليين المرفقين وملفي الاختبار المحددين. DOCX غير مدعوم ضمن أنواع الاستيراد المطلوبة. هذه الجولة لا تمثل اختبار كل خط أو كل حجم شاشة أو كل تركيبة Light/Dark؛ توجد اختبارات آلية للتجاوب وRTL والوضع الداكن، ولا تُقدّم كبديل عن فحص بصري لكل تلك التركيبات.
